# Plan: Vugu Demo App for postgres-event-bus

## Goal
Create a Vugu-based demo application at `~/IdeaProjects/peb-demo` that uses the postgres-event-bus outbox layer to fire events on Candidate/Job CRUD operations, with a live-updating web UI that shows the events as they flow through the bus.

## Current Context / Assumptions

- **postgres-event-bus** is on branch `implement-outbox` at `~/IdeaProjects/postgres-event-bus`, all 15 integration tests pass.
- **Go**: v1.26+ available, module path is `github.com/stealthtalent/postgres-event-bus`.
- **Postgres**: accessible at `localhost:8432`, database `eventbus_test`, credentials from docker-compose.
- **GOPRIVATE**: `github.com/stealthtalent/*` is already set (or will be) so the private module resolves.
- **Vugu**: v0.2+ (latest), compatible with Go 1.26.
- **Browser**: the developer has a modern browser (Chrome/Firefox) to view the demo at `http://localhost:8080`.
- **LM Studio / Gemma 4**: available via `hermes -p lm-studio` if AI assistance is needed mid-task.

## Architecture / Proposed Approach

The demo app is a standalone Go program (`main.go`) that:
1. Boots an in-process HTTP server (Vugu + standard `net/http`).
2. Uses a single Postgres pool for both the CRUD repositories and the event bus.
3. Uses the **outbox layer** (`Bus.Publish`, `Bus.RunDispatcher`, `Bus.RunGroup`) exclusively — not the raw `Queue` API — to demonstrate the full transactional-outbox pattern.
4. Has a Vugu UI with two tabs (Jobs, Candidates), each showing a list + "create" form, plus a third "Event Log" tab that live-renders all dispatched events.

The event flow: CRUD handler runs `Publish(ctx, tx, ...)` inside the same transaction as the DB INSERT → `RunDispatcher` picks it up → inserts into `message_queue` for the group → `RunGroup` drains the queue and appends the event to an in-memory event log → Vugu UI refreshes via `vugu.DOMUpdate`.

```go
package repositories

import (
    "context"
    "fmt"
    "time"

    "github.com/jackc/pgx/v5/pgxpool"
    "github.com/stealthtalent/peb-demo/src/models"
)

type pgJobRepo struct {
    pool *pgxpool.Pool
}

func NewPGJobRepository(pool *pgxpool.Pool) JobRepository {
    return &pgJobRepo{pool: pool}
}

func (r *pgJobRepo) Create(ctx context.Context, j *models.Job) error {
    j.ID = fmt.Sprintf("job_%d", time.Now().UnixNano())
    j.CreatedAt = time.Now()
    _, err := r.pool.Exec(ctx,
        `INSERT INTO jobs (id, title, created_at) VALUES ($1, $2, $3)`,
        j.ID, j.Title, j.CreatedAt)
    return err
}

func (r *pgJobRepo) List(ctx context.Context) ([]models.Job, error) {
    rows, err := r.pool.Query(ctx, `SELECT id, title, created_at FROM jobs ORDER BY created_at DESC`)
    if err != nil {
        return nil, err
    }
    defer rows.Close()
    var jobs []models.Job
    for rows.Next() {
        var j models.Job
        if err := rows.Scan(&j.ID, &j.Title, &j.CreatedAt); err != nil {
            return nil, err
        }
        jobs = append(jobs, j)
    }
    return jobs, nil
}

func (r *pgJobRepo) Get(ctx context.Context, id string) (*models.Job, error) {
    var j models.Job
    err := r.pool.QueryRow(ctx,
        `SELECT id, title, created_at FROM jobs WHERE id = $1`, id).
        Scan(&j.ID, &j.Title, &j.CreatedAt)
    if err != nil {
        return nil, err
    }
    return &j, nil
}
```

```go
import (
```

```go
// EventFiringJobRepo wraps a JobRepository and fires a "job.created" event
// inside the caller's transaction.
type EventFiringJobRepo struct {
    inner  JobRepository
    bus    *eventbus.Bus
}

func NewEventFiringJobRepo(inner JobRepository, bus *eventbus.Bus) *EventFiringJobRepo {
    return &EventFiringJobRepo{inner: inner, bus: bus}
}

func (r *EventFiringJobRepo) Create(ctx context.Context, tx pgx.Tx, job *Job) error {
    // Start a savepoint-friendly unit: the caller manages the tx.
    // We just need to insert + publish in the same tx.
    _, err := tx.Exec(ctx,
        `INSERT INTO jobs (id, title, created_at) VALUES ($1, $2, $3)`,
        job.ID, job.Title, job.CreatedAt)
    if err != nil {
        return err
    }
    _, err = r.bus.Publish(ctx, tx, eventbus.PublishParams{
        Type:        "job.created",
        OrderingKey: job.ID,
        Payload: map[string]any{
            "id":        job.ID,
            "title":     job.Title,
            "created_at": job.CreatedAt.Format(time.RFC3339),
        },
    })
    return err
}
```

```go
package middleware

import (
    "context"
    "fmt"
    "time"

    "github.com/jackc/pgx/v5"
    "github.com/jackc/pgx/v5/pgxpool"
    eventbus "github.com/stealthtalent/postgres-event-bus/api"
    "github.com/stealthtalent/peb-demo/src/models"
)

type EventBus struct {
    bus *eventbus.Bus
}

func NewEventBus(bus *eventbus.Bus) *EventBus {
    return &EventBus{bus: bus}
}

// WithTxJobRepos creates repositories that fire events within a shared transaction.
// The caller begins the tx, calls Create, then commits — all in one tx.
type JobRepos struct {
    pool *pgxpool.Pool
    bus  *eventbus.Bus
}

func NewJobRepos(pool *pgxpool.Pool, bus *eventbus.Bus) *JobRepos {
    return &JobRepos{pool: pool, bus: bus}
}

func (r *JobRepos) CreateWithEvents(ctx context.Context, title string) (models.Job, error) {
    tx, err := r.pool.Begin(ctx)
    if err != nil {
        return models.Job{}, err
    }
    defer func() { _ = tx.Rollback(ctx) }()

    j := models.Job{
        ID:        fmt.Sprintf("job_%d", time.Now().UnixNano()),
        Title:     title,
        CreatedAt: time.Now(),
    }

    _, err = tx.Exec(ctx,
        `INSERT INTO jobs (id, title, created_at) VALUES ($1, $2, $3)`,
        j.ID, j.Title, j.CreatedAt)
    if err != nil {
        return models.Job{}, err
    }

    _, err = r.bus.Publish(ctx, tx, eventbus.PublishParams{
        Type:        "job.created",
        OrderingKey: j.ID,
        Payload: map[string]any{
            "id":         j.ID,
            "title":      j.Title,
            "created_at": j.CreatedAt.Format(time.RFC3339),
        },
    })
    if err != nil {
        return models.Job{}, err
    }

    if err := tx.Commit(ctx); err != nil {
        return models.Job{}, err
    }
    return j, nil
}

func (r *JobRepos) List(ctx context.Context) ([]models.Job, error) {
    rows, err := r.pool.Query(ctx, `SELECT id, title, created_at FROM jobs ORDER BY created_at DESC`)
    if err != nil {
        return nil, err
    }
    defer rows.Close()
    var jobs []models.Job
    for rows.Next() {
        var j models.Job
        if err := rows.Scan(&j.ID, &j.Title, &j.CreatedAt); err != nil {
            return nil, err
        }
        jobs = append(jobs, j)
    }
    return jobs, nil
}

type CandidateRepos struct {
    pool *pgxpool.Pool
    bus  *eventbus.Bus
}

func NewCandidateRepos(pool *pgxpool.Pool, bus *eventbus.Bus) *CandidateRepos {
    return &CandidateRepos{pool: pool, bus: bus}
}

func (r *CandidateRepos) CreateWithEvents(ctx context.Context, name, email string) (models.Candidate, error) {
    tx, err := r.pool.Begin(ctx)
    if err != nil {
        return models.Candidate{}, err
    }
    defer func() { _ = tx.Rollback(ctx) }()

    c := models.Candidate{
        ID:        fmt.Sprintf("cand_%d", time.Now().UnixNano()),
        Name:      name,
        Email:     email,
        CreatedAt: time.Now(),
    }

    _, err = tx.Exec(ctx,
        `INSERT INTO candidates (id, name, email, created_at) VALUES ($1, $2, $3, $4)`,
        c.ID, c.Name, c.Email, c.CreatedAt)
    if err != nil {
        return models.Candidate{}, err
    }

    _, err = r.bus.Publish(ctx, tx, eventbus.PublishParams{
        Type:        "candidate.created",
        OrderingKey: c.ID,
        Payload: map[string]any{
            "id":         c.ID,
            "name":       c.Name,
            "email":      c.Email,
            "created_at": c.CreatedAt.Format(time.RFC3339),
        },
    })
    if err != nil {
        return models.Candidate{}, err
    }

    if err := tx.Commit(ctx); err != nil {
        return models.Candidate{}, err
    }
    return c, nil
}

func (r *CandidateRepos) List(ctx context.Context) ([]models.Candidate, error) {
    rows, err := r.pool.Query(ctx, `SELECT id, name, email, created_at FROM candidates ORDER BY created_at DESC`)
    if err != nil {
        return nil, err
    }
    defer rows.Close()
    var candidates []models.Candidate
    for rows.Next() {
        var c models.Candidate
        if err := rows.Scan(&c.ID, &c.Name, &c.Email, &c.CreatedAt); err != nil {
            return nil, err
        }
        candidates = append(candidates, c)
    }
    return candidates, nil
}
```

```go
package eventlog

import (
    "sync"
    "time"
)

type Entry struct {
    ID        string         `json:"id"`
    Type      string         `json:"type"`
    Payload   map[string]any `json:"payload"`
    Timestamp time.Time      `json:"timestamp"`
}

type Log struct {
    mu      sync.Mutex
    entries []Entry
}

func NewLog() *Log {
    return &Log{}
}

func (l *Log) Append(e Entry) {
    l.mu.Lock()
    defer l.mu.Unlock()
    e.Timestamp = time.Now()
    l.entries = append(l.entries, e)
}

func (l *Log) All() []Entry {
    l.mu.Lock()
    defer l.mu.Unlock()
    out := make([]Entry, len(l.entries))
    copy(out, l.entries)
    return out
}
```

```go
package main

import (
    "context"
    "net/http"
    "time"

    "github.com/jackc/pgx/v5/pgxpool"
    eventbus "github.com/stealthtalent/postgres-event-bus/api"
    "github.com/stealthtalent/peb-demo/src/middleware"
    "github.com/stealthtalent/peb-demo/src/ui"
)

func main() {
    ctx := context.Background()

    // Connect to Postgres
    pool, err := pgxpool.New(ctx, "postgres://test@127.0.0.1:8432/peb_demo?sslmode=disable")
    if err != nil {
        panic(err)
    }
    defer pool.Close()

    // Apply demo schema
    // ... (exec schemas/demo.sql)

    // Set up the event bus
    bus := eventbus.NewBus(pool, eventbus.Config{
        Batch:          10,
        PollInterval:   5 * time.Second,
        MaxAttempts:    5,
    })

    jobRepos := middleware.NewJobRepos(pool, bus)
    canRepos := middleware.NewCandidateRepos(pool, bus)
    eventLog := eventlog.NewLog()

    // Start dispatcher (writes to message_queue channel "demo-group")
    go func() {
        _ = bus.RunDispatcher(ctx, eventbus.DispatcherOptions{
            Group: "demo-group",
        })
    }()

    // Start group worker — writes events to the in-memory log
    go func() {
        _ = bus.RunGroup(ctx, eventbus.GroupOptions{
            Group: "demo-group",
        }, func(ctx context.Context, tx pgx.Tx, e eventbus.Event) error {
            var payload map[string]any
            _ = json.Unmarshal(e.Payload, &payload)
            eventLog.Append(eventlog.Entry{
                ID:      e.ID,
                Type:    e.Type,
                Payload: payload,
            })
            return nil
        })
    }()

    // Vugu UI
    http.Handle("/", vugu.NewHandler(ctx, &ui.App{
        JobRepos:     jobRepos,
        CandidateRepos: canRepos,
        EventLog:     eventLog,
    }))

    // API endpoints for CRUD actions
    http.HandleFunc("/api/jobs", func(w http.ResponseWriter, r *http.Request) {
        switch r.Method {
        case http.MethodPost:
            // Create + fire event
        case http.MethodGet:
            // List
        }
    })

    // Similar for /api/candidates

    http.ListenAndServe(":8080", nil)
}
```

## Risks, Tradeoffs, and Open Questions

- **Vugu learning curve**: The implementer may not know Vugu's component model or reactivity system. Suggest spending 30 min on the Vugu docs first.
- **Single DB connection**: Using a single `pgxpool` for both CRUD and the bus is fine for a demo, but `RunDispatcher` and `RunGroup` will consume connections. Configure `max_conns` appropriately (e.g., 20).
- **Event log visibility**: The in-memory log is ephemeral. Consider adding a `demo_events` table if persistence across restarts is desired.
- **No auth**: This is a demo — no authentication is needed.
- **Transaction scope**: The middleware's `CreateWithEvents` pattern begins/commits its own transaction. If the caller needs to do more work in the same tx, the pattern needs to accept a `pgx.Tx` parameter instead. This is a simplification for the demo.
- **Schema migration**: Should the demo use dbmate like the main project, or just raw SQL? For simplicity, raw SQL loaded at startup.
